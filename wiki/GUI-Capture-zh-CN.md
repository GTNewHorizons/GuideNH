# GUI 截图

[English](GUI-Capture.md)

在按键设置的 GuideNH 分类中绑定“打开 GUI 截图”，该按键默认未绑定。打开 GUI 后按下绑定键进入截图覆盖层。工具栏和设置面板采用半透明布局，导出图片不包含截图工具本身。

## 框选和保存

拖动创建选区，松开后固定；拖动边角可调整大小。吸附支持格子、组件、窗口和已有适配的模组界面层，可显示悬停目标的类名。使用添加选区按钮，或按住 Ctrl 拖动，可添加更多选区。

默认输出所有正选区的外接矩形，包含选区之间的间隙。使用擦除工具清除不需要的部分；重叠选区不会重复绘制像素。独立选区导出、横向、纵向和网格排列是可选设置。

点击保存图标或按 Enter 保存。设置面板可调整尺寸、输出格式、背景、内容层、吸附、输出目录和资源预算。默认不包含背后的世界，GUI 内部模型仍属于 GUI 内容。工具提示、调试、NEI 和 GUI 背景分别配置。

捕获源和像素读回器选项会显示已注册的提供器。自动源在关闭世界包含时使用 GUI 独立层，开启时使用不透明的最终帧；显式选择不兼容的源会显示原因。成功切换会更新预览，拒绝选择时保留当前预览，设置页底部显示实际使用的实现。录制和导出在任务结束前保留源、读回器及内容快照；能力快照变化时重建空闲资源，并暂停受影响的录制。

| 按键 | 操作 |
| --- | --- |
| Enter | 保存；录制时停止录制 |
| Esc | 关闭面板、取消当前拖动或退出截图 |
| Delete | 删除活动选区 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做选区编辑 |
| Ctrl+D | 复制活动选区 |
| Ctrl+A | 选择整个 GUI 视口 |
| 方向键 | 移动活动选区 1 个 GUI 像素 |
| Shift+方向键 | 移动 10 个 GUI 像素 |
| Ctrl+方向键 | 调整活动选区大小 |
| 录制时按空格 | 暂停 / 恢复 |

每个轴的输出分辨率不超过源尺寸的 32 倍。支持重绘的 GUI 使用分块处理大图。无法安全重绘的源是否可以使用原生截图或重采样，取决于所选质量策略；选择时可查看界面显示的质量和后端能力。

HUD 和光标分别设置，默认均关闭。包含 HUD 时，在正常 HUD 绘制前准备所选 GUI 层，同时接入 Angelica 的 HUD 缓存入口。冻结预览时，GUI 绘制和 Forge 绘制事件沿用原界面指针；导出的软件光标使用现有黑白透明截图图集，并接入安全的分块 GUI 快照。高分辨率 HUD 安全重绘仍待补齐：当前严格质量模式拒绝此组合，兼容输出放大完整原生 HUD/GUI 帧。

## 录制和定时

选择 GIF、PNG 精灵图或 PNG 帧序列，设置帧率、时长或帧数上限，再开始录制。覆盖层提供暂停、恢复、停止和取消操作。精灵图的 JSON 记录帧矩形和时间；GIF 使用配置的透明阈值或底色。

定时功能支持延迟、本地指定时刻和重复捕获。失焦或 GUI 不可用时，按不可用目标策略等待、跳过或结束。录制队列与临时输出都有可调整的预算。

## 批量捕获

点击捕获全部图标，先查看并选择目标。可见层、页面和可达 GUI 是互相独立的范围设置；提供器、弹窗、变体、导航超时、目标上限和恢复行为均可配置。可达服务端容器需要截图协议和合法服务端上下文，目录和结果会显示不可用原因或失败。

开启联系表可生成分页缩略图，并选择按提供器分组。开启滚动长图后，已有适配的 GuideNH、NEI、MUI1 和 BetterQuesting 滚动切片按文档位置合成。MUI1 支持嵌套页签、横纵向滚动控件和列表，批量结束后恢复页签与滚动位置。固定控件保留在独立的原始视口截图中；最后一个切片的重叠部分直接覆盖前面的像素，不重复叠加透明度。

`betterquesting_pages` 提供器支持从任务首页、章节阅读器或任务详情页开始，遍历可进入的章节和可见任务，并捕获描述、任务、奖励及地图的滚动内容。地图输出按实际组件边界计算，支持负坐标，不包含仅供手动拖动的大片空白范围。隐藏内容不会进入目录，导航被锁定的可见章节明确显示不可用。页面导航前需关闭 BQ 模态弹窗。恢复时保留原章节、书签、缩放、滚动位置及任务滚动缓存，不清空无关缓存；捕获不会检测或领取任务、发放奖励或开启编辑模式。

`thaumcraft_pages` 提供器支持从原生研究浏览器或配方书开始，列出可进入类别及可见研究，并通过原生配方书构造器打开已完成研究；隐藏文本过滤和动态要素页由构造器处理后，再展开实际双页。未完成的可见研究显示不可用，隐藏研究排除。类别地图切片按可见研究边界、原生平移限制和裁剪后的 224×196 地图区计算，长图排除固定控件，固定控件保留在类别视口截图中。目标限制明确报告剩余地图切片，缺失覆盖保留部分完成状态。恢复原类别、地图插值/目标位置、浏览器记忆位置及配方历史；捕获不会解锁研究或消耗研究资源。代码已接入，完整验收仍留到全部实现后进行。

`batch.json` 记录逐项目标结果、恢复状态和合成输出。每份长图包含 `scroll.png` 和 `scroll.json`，记录来源裁剪、目标矩形、像素比例和覆盖范围。目标上限或缺少切片会产生明确的部分完成结果，并保留未覆盖区域。联系表和长图使用批量任务的剩余磁盘预算，取消或失败时清理未发布的临时合成文件。

## 开发接入

通过截图接口分别注册几何提供器、GUI 渲染器、捕获源、像素读回器、批量提供器和输出编码器。使用 `CaptureRegistry.registerSource` 注册 `CaptureSourceProvider`，使用 `registerReader` 注册 `CapturePixelReaderProvider`。提供器报告可用性时不分配捕获缓冲区，管线在需要时才打开资源。自动选择优先使用最后注册的可用提供器。上下文键需包含资源所依赖的屏幕、渲染上下文或能力代次。源收到配对的 GUI 开始/完成回调。`CaptureSource.capturePhase` 可选择 `WORLD_READY`、`GUI_BEGIN`、`GUI_END` 或 `FRAME_READY`，默认使用 `FRAME_READY`；通用 `capture` 回调保留旧的完整帧回调兼容。源在选择的阶段返回视口尺寸像素，提前捕获的帧由运行时持有至呈现阶段；不重定向 GUI 绘制的源也会收到完成回调。

在客户端线程且没有活动捕获任务时，可用 `CaptureRuntime.selectSource` 和 `selectReader` 按 ID 选择。失败选择保留原预览，成功切换会作废旧预览并请求新帧。读回器接收明确的源 Alpha 模式，返回直通 ARGB 帧，并在会话关闭时释放资源。原生 GUI 层和分块导出使用相同读回接口。`CaptureFrameIdentity` 记录实际后端、请求选项及捕获内容，导出选项冻结实际实现 ID；批量结果通过 `capture.source` 和 `capture.reader` 记录来源，包括保留的可见层帧。

在客户端线程通过 `CaptureRegistry.registerPhaseListener` 注册 `CapturePhaseListener`，可观察顺序固定的四阶段边界。`CaptureContext` 携带阶段及观测渲染状态。`WORLD_READY` 位于世界及 shader-group 绘制完成后，`GUI_END` 位于屏幕渲染器返回后，`FRAME_READY` 位于后置层和主帧缓冲 blit 完成、提交呈现之前。GUI 独立层包含 RenderTick End 后置绘制，最终帧源读取呈现 back buffer。`CaptureFrameIdentity.readback` 保留捕获阶段、实际读回目标和四阶段不可变快照。批量数据记录 `capture.frame`、`capture.phase`、`capture.phases`、`capture.backend`、`capture.opengl`、帧缓冲/缓冲编号、viewport 和 shadow-pass 状态。硬件 PBO/fence 能力标记仅表示硬件支持，异步读回器仍待实现。

客户端 GUI 导航采用 Forge 初始化后实际打开的屏幕，支持 Angelica 视频设置等同步替换；打开被取消时明确报告失败。

滚动导航器可从 `CaptureBatchNavigator.scrollGeometry` 返回 `CaptureScrollGeometry`；编码模块读取导出帧，不依赖模组 GUI 的实现。继承容器界面但拥有独立更新生命周期的界面，可实现 `StandaloneContainerScreen` 并提供 `updateStandaloneScreen`。

兼容情况取决于实际模组版本和渲染后端，完整的着色器、后端及模组验收矩阵仍在进行中。

Angelica 为当前 `RenderBackend` 注册 `angelica` 像素读回器，通过后端 API 读取打包像素，并在转换为直通 ARGB 前恢复像素打包参数和缓冲绑定。加载 Angelica 时，自动读回选择使用该实现；SDL GPU 下显式选择 `opengl` 会显示不可用原因。源的资源键同时保留原源的上下文键与实际后端身份。原生与后端读回器通过 `CaptureBufferPixelReader` 共享缓冲复用、行方向和 Alpha 转换；后端回调填充从下到上的 ARGB 数值，并恢复它修改的状态。

直接后端读回器已有 OpenGL 验收结果。开发环境通过临时启动库补齐 shaderc/spvc 后已初始化 SDL GPU Vulkan；按全部实现完成后再验收的新要求，捕获验收已停止。非 GL 捕获、着色器包和指定 Prism 实例仍未验证。工具不会自动修改渲染后端或着色器偏好。
