# 语法智能补全

在游戏内指南编辑器中编写页面时，编辑器会提供标签、属性和取值候选。

## 编写参考

点击游戏内编辑器工具栏的灯泡打开编写参考。左侧导航可搜索主题标题、标签属性、YAML 字段和示例代码；Ctrl+F 聚焦搜索，右键清空。选择主题会在完整文档中跳到对应标题。导航与正文滑条均平滑滚动。

前进、后退按钮可重新访问主题并恢复滚动位置。悬停右侧滑条上的标题横线可查看标题，点击可跳转。代码块按钮复制示例，工具栏复制按钮复制所选主题的 Markdown。参考打开时灯泡保持蓝色，再次点击灯泡返回指南页，保留草稿、选区和撤销历史。关闭按钮或 Esc 关闭指南窗口。文档跟随游戏语言，缺少译文时回退英文。

## 使用候选列表

| 操作 | 结果 |
| --- | --- |
| ↑ / ↓ | 选择上一项或下一项 |
| Tab / Enter | 插入选中的候选 |
| 单击候选 | 插入选中的候选 |
| Esc | 关闭列表 |
| 鼠标滚轮 | 滚动候选列表 |
| 滑条 | 拖动滑条滚动 |

## 支持的补全

| 编辑位置 | 候选内容 |
| --- | --- |
| `<...` | 当前容器内可用的标签名 |
| `<Tag ...` | 属性名及对应的取值定界符 |
| `id="..."`, `fluid="..."` | 物品和流体注册名、配方、页面、资源及其他支持的取值 |
| Markdown | 标题、列表、表格、提示块等 Markdown 结构 |
| 代码围栏 | 支持的代码语言和 GuideNH 围栏名 |
| Frontmatter | YAML 字段及支持的取值 |

补全标签名会插入空标签或成对标签，成对标签的光标位于内部，再按需填写属性和内容。物品与流体的取值候选左侧带有图标；流体使用 `water`、`steam` 等注册名，不使用数字 ID。

### 任务与研究 ID

ID 候选由当前内容决定：

| 编写位置 | ID 来源 |
| --- | --- |
| `ResearchLink`、`ResearchCard`、`ResearchIcon` | Thaumcraft 研究 |
| `QuestLink`、`QuestCard` | BetterQuesting 任务 |
| `bindings` 条目中的 `id` | 同一条目 `type` 指定的系统 |
| `BindingLink`、`BindingCard`、`BindingIcon` | 标签 `type` 指定的系统 |

填写绑定时，先写 `type`，再选择 `id`：

```yaml
bindings:
  - {type: "thaumcraft", id: "INFUSION", anchor: "infusion"}
```

游戏内编辑器读取已加载模组的 ID。两种 IDE 插件离线时也会建议工作区页面已使用的 ID；连接运行中的游戏后，可以查询游戏注册的 ID。研究 ID 保留原始大小写。查找与复制方法见 [Thaumcraft 兼容](Mod-Compatibility-zh-CN#查看与复制研究-id)。

## 多行文本与模板

候选行使用简短预览。可见的 `\n`、`\t` 表示换行和制表符，确认候选后会插入实际文本。多行插入沿用当前位置的缩进，并将光标放在继续填写的位置。

需要完整示例时，在编辑器右键菜单中选择模板，场景和图表模板均在此提供。普通标签名补全保留空标签。

## NEI 动作链接

插入菜单提供处理器全部配方、物品合成配方、物品用途的动作片段，以及 `<NeiRecipeLink>`。`id` 属性提供物品 ID 补全，`mode` 提供 `handler`、`recipes` 和 `usage`。`handlerId` 填写 NEI 的精确标识。

语法和示例见[配方](Recipes-zh-CN#行内-nei-配方链接)。
