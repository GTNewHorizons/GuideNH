# 服务端集成

阅读指南、搜索和场景预览由客户端完成。玩家的指南资源来自客户端安装的模组或资源包；服务端不会分发页面内容。

## 部署

| 功能 | 客户端 | 服务端 |
| --- | --- | --- |
| 阅读、搜索、场景预览 | 安装 GuideNH 及指南资源 | 无须安装 GuideNH |
| 将结构放入世界、使用 `/guidenh` | 安装 GuideNH | 安装 GuideNH，放置者具有 3 级命令权限 |

仅客户端安装时，世界放置功能不可用。需要使用场景导出操作时，检查 `sceneExportEnabled` 设置。单人游戏中的世界放置也受作弊/命令权限限制。

## 管理员命令

由玩家执行，坐标支持 `~` 相对坐标：

| 命令 | 用途 |
| --- | --- |
| `/guidenh importstructure <x> <y> <z>` | 打开客户端结构导入窗口，并填入目标坐标 |
| `/guidenh placeallstructures <x> <y> <z>` | 从目标坐标起沿 X 轴依次放置该玩家缓存的结构 |

两条命令以及单个结构放置均要求 3 级命令权限。导入和批量放置使用玩家本次登录的结构缓存，退出后清空；缓存不是长期保存的服务器资源。

## 排查

1. 世界放置不可用：确认服务端已安装 GuideNH，并检查场景导出设置。
2. 提示权限不足：检查玩家的命令权限等级，单人游戏也需允许相关命令。
3. 批量放置没有结构：重新导入或缓存结构；重新登录会清空缓存。
4. 页面缺失或内容过期：检查客户端资源包，并按 `F3+T` 重载。
