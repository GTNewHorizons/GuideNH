# Аннотации

Аннотации сцены GuideNH являются дочерними тегами внутри `<GameScene>` / `<Scene>`. Они отображаются в мировом пространстве и могут содержать дочернее содержимое Markdown и тегов, которое становится подробной подсказкой.

## Общие правила

- аннотации работают только внутри сцены.
- дочернее содержимое становится телом всплывающей подсказки.
- аннотации можно скрыть с помощью переключателя пользовательского интерфейса сцены.
- `alwaysOnTop` рисует геометрию над сценой, если это поддерживается типом аннотации.
- все аннотации сцены также принимают дополнительные элементы `showWhenStructure`, `showWhenTier` и `showWhenChannels`, когда сцена использует `<ImportStructureLib>`.

## Поддерживаемые теги аннотаций

- `<BlockAnnotation>`
- `<BoxAnnotation>`
- `<LineAnnotation>`
- `<DiamondAnnotation>`
- `<TextAnnotation>`

GuideNH также поддерживает `<BlockAnnotationTemplate>`, применяющий свои дочерние аннотации к каждому уже размещённому подходящему блоку текущей сцены.

## Условия StructureLib

Если сцена содержит `<ImportStructureLib>`, каждый тег аннотации может ограничивать свою видимость определенным
состояния StructureLib:

| Атрибут | Значение |
| --- | --- |
| `showWhenStructure` | привяжите аннотацию к именованному `<ImportStructureLib name="...">`; опустите его, если сцена импортирует только одну структуру StructureLib. |
| `showWhenTier` | фильтр уровня, например `2`, `1..3`, `!2` или `1..5,!3`. |
| `showWhenChannels` | поканальный фильтр, например `input:1..3, casing:!2, fluid:4`. |

Правила:

- `showWhenTier` и `showWhenChannels` объединяются логическим И.
- `showWhenChannels` может упоминать несколько каналов в одном атрибуте.
- предложения только с отрицанием, такие как `!2`, означают «любое значение, кроме 2».
- те же атрибуты поддерживаются дочерними аннотациями `<PlaySound>` и `<BlockAnnotationTemplate>`.

Пример:

````md
<GameScene interactive={true}>
  <ImportStructureLib name="main" controller="gregtech:gt.blockmachines:15411" />

  <BlockAnnotation
    pos="5 1 2"
    color="#FFD24C"
    showWhenStructure="main"
    showWhenTier="2..4,!3"
    showWhenChannels="input:1..3, casing:!2"
  >
    Отображается только для выбранного состояния StructureLib.
  </BlockAnnotation>
</GameScene>
````

## `<BlockAnnotation>`

Выделяет объём одного блока размером 1x1x1.

| Атрибут | Обязательно. | Значение |
| --- | --- | --- |
| `pos` | да | `x y z` вектор |
| `color` | нет | `#RRGGBB`, `#AARRGGBB` или `transparent`. |
| `thickness` | нет | плавающая толщина линии |
| `alwaysOnTop` | нет | логическое выражение |

Пример:

````md
<BlockAnnotation pos="2 0 2" color="#33DDEE" alwaysOnTop={true}>
  Выделяет блок-контроллер.
</BlockAnnotation>
````

## `<BoxAnnotation>`

Выделяет произвольную рамку, выровненную по осям.

| Атрибут | Обязательно. | Значение |
| --- | --- | --- |
| `min` | да | минимальный вектор `x y z` |
| `max` | да | `x y z` максимальный вектор |
| `color` | нет | цвет аннотации |
| `thickness` | нет | плавающая толщина линии |
| `alwaysOnTop` | нет | логическое выражение |

GuideNH автоматически меняет местами минимальные и максимальные координаты для каждой оси, если они указаны в обратном порядке.

Пример:

````md
<BoxAnnotation min="0 1 0" max="1 1.6 0.6" color="#EE3333" thickness="0.04">
  Выделяет область половинной высоты.
</BoxAnnotation>
````

## `<LineAnnotation>`

Рисует отрезок или полилинию в мировом пространстве.

| Атрибут | Обязательно. | Значение |
| --- | --- | --- |
| `from` | да, если не установлено `points`. | `x y z` стартовый вектор |
| `to` | да, если не установлено `points`. | Конечный вектор `x y z` |
| `points` | нет | точки для ломаной линии, разделенные точкой с запятой. `x y z`; переопределяет `from` / `to` |
| `color` | нет | цвет аннотации |
| `thickness` | нет | плавающая толщина линии |
| `alwaysOnTop` | нет | логическое выражение |
| `arrow` | нет | `start` или `end`; если атрибут опущен, стрелка не отображается |
| `showPoints` | нет | логическое выражение; показывает каждую точку как маленький куб |
| `pointColor` | нет | цвет куба по умолчанию; опущено, используется цвет линии |
| `pointSize` | нет | размер куба по умолчанию; опущено, используется значение немного большее, чем `thickness`. |

`LineAnnotation` может содержать дочерние теги `<LinePoint>` для настройки отдельных маркеров. Этот тег
использует `index` и необязательные `show`, `color` и `size`; индексация точек начинается с нуля.
Стрелки можно размещать только в начале или конце строки; промежуточные точки полилинии не могут нести
стрелки.

Пример:

````md
<LineAnnotation from="0.5 1.2 0.5" to="2.5 1.2 2.5" color="#FFD24C" thickness="0.08">
  Сигнальный путь.
</LineAnnotation>
````

Полилиния со стрелкой конечной точки 3D и выбранными маркерами точек:

````md
<LineAnnotation
  points="0.5 1.2 0.5; 1.5 1.7 0.5; 2.5 1.2 2.5"
  color="#FFD24C"
  thickness="0.08"
  arrow="end"
>
  <LinePoint index="0" show color="#66CCFF" />
  <LinePoint index="1" show color="#FF8844" size="0.12" />
  Сигнальный путь с изгибом.
</LineAnnotation>
````

## `<DiamondAnnotation>`

Помещает обращённый к экрану ромбовидный маркер в указанную мировую позицию.

| Атрибут | Обязательно. | Значение |
| --- | --- | --- |
| `pos` | да | позиция маркера `x y z` |
| `color` | нет | цвет оттенка; опущены, по умолчанию ярко-зеленый |

Пример:

````md
<DiamondAnnotation pos="0.5 2.2 0.5" color="#FFD24C">
  ### Активированный маяк
  Наведите курсор, чтобы открыть подробное содержимое.
</DiamondAnnotation>
````

## `<TextAnnotation>`

Рисует над сценой текстовую метку в виде речевого облака. Она может следовать за точкой привязки в мировом пространстве
или оставаться неподвижной относительно центра сцены. В отличие от других аннотаций, дочернее содержимое является самим
текстом облака, а не отдельной подсказкой.

| Атрибут | Обязательно. | Значение |
| --- | --- | --- |
| `pos` | нет | `x y z` вектор привязки мирового пространства |
| `x`, `y`, `z` | нет | альтернативные компоненты привязки мирового пространства, если `pos` опущен. |
| `text` | нет | текст в виде всплывающей подсказки; дочерний markdown используется, если опущен |
| `textKey` | нет | ключ перевода разрешен из файлов пакета ресурсов `lang` перед возвратом к `text` или дочернему markdown. |
| `color` | нет | Цвет границы пузырька; по умолчанию светло-серый |
| `backgroundAlpha` | нет | прозрачность фона от `0` до `255`; по умолчанию `204` |
| `maxWidth` | нет | Ширина переноса в пикселях; `0` сохраняет одну строку. |
| `independent` | нет | `true` удерживает пузырь в пространстве экрана. |
| `yOffset` | нет | смещение пикселей от центра сцены при `independent={true}`. |
| `connectorSide` | нет | `bottom`, `top`, `left`, `right` или `none`; по умолчанию `bottom` |
| `connectorOffset` | нет | смещение пикселей по краю пузырька; положительные перемещения вправо для верха/низа и вниз для левого/правого |
| `connectorLength` | нет | Длина соединительной линии в пикселях; по умолчанию `6` |
| `hlMinX/Y/Z`, `hlMaxX/Y/Z` | нет | Необязательные границы сопутствующего поля выделения. |
| `highlightColor` | нет | дополнительный цвет выделения. |

Облака, привязанные к миру, соединяются линией со своей точкой привязки. `connectorSide` выбирает сторону облака,
к которой крепится линия, `connectorOffset` перемещает точку вдоль этой стороны, а `connectorLength` задаёт зазор
между облаком и привязкой. Независимые облака центрируются по горизонтали; для вертикального смещения используйте
`yOffset`. Они не рисуют соединитель. Эта же аннотация времени выполнения используется при импорте аннотаций Ponder `text`.

Пример:

````md
<TextAnnotation
  pos="1.5 2 1.5"
  textKey="guidenh.sample.scene.insert_items"
  color="#FF44AAFF"
  maxWidth={120}
  backgroundAlpha={180}
  connectorSide="right"
  connectorOffset={8}
  connectorLength={12}
>
  Вставьте предметы сюда с **учётом приоритета**.
</TextAnnotation>
````

Пример фиксированного экранного пространства:

````md
<TextAnnotation independent={true} yOffset={40} color="#FFFFCC00" backgroundAlpha={140}>
  Независимый текст состояния
</TextAnnotation>
````

## Богатое содержание всплывающих подсказок

дочерние аннотации компилируются как обычное содержимое GuideNH, поэтому всплывающие подсказки могут содержать:

- markdown абзацев и заголовков
- изображения элементов/блоков.
- рецепты
- вложенные неинтерактивные сцены.

Пример:

````md
<DiamondAnnotation pos="0.5 1.5 0.5">
  **Machine Core**
  <RecipeFor id="minecraft:furnace" />
</DiamondAnnotation>
````

## `<BlockAnnotationTemplate>`

Используйте этот тег, чтобы нанести одну и ту же аннотацию на каждый подходящий блок.

| Атрибут | Обязательно. | Значение |
| --- | --- | --- |
| `id` | да | сопоставитель блоков в форме `modid:block[:meta]`. |

Правила:

- шаблон видит только те блоки, которые уже существуют при его анализе.
- поместите его после тегов `<Block>`, `<ImportStructure>` или `<ImportStructureLib>`, которые должны его кормить.
- дочерние аннотации используют локальные координаты относительно каждого сопоставленного блока.

Пример:

````md
<GameScene zoom={2}>
  <ImportStructure src="/assets/example_structure.snbt" />
  <BlockAnnotationTemplate id="minecraft:log">
    <DiamondAnnotation pos="0.5 0.5 0.5" color="#ff0000">
      Подсказка, созданная шаблоном
    </DiamondAnnotation>
  </BlockAnnotationTemplate>
</GameScene>
````
