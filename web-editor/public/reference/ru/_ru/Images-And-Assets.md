# Изображения и ресурсы

GuideNH поддерживает как обычные изображения markdown, так и несколько визуальных элементов, специфичных для среды выполнения.

## Правила поиска ресурсов

Ресурсы руководства разрешаются по тем же правилам, что и ссылки на страницы.

| Форма пути | Пример | Значение |
| --- | --- | --- |
| относительный | `test1.png` | относительно текущего файла страницы. |
| рутирован | `/assets/example_structure.snbt` | относительно текущего корня руководства. |
| явный идентификатор ресурса | `guidenh:textures/gui/example.png` | абсолютный поиск `modid:path` |

## Изображения Markdown

Поддерживаются обычные изображения markdown:

````md
![Пример](test1.png)
````

GuideNH разрешает путь и загружает двоичный ресурс из корня содержимого руководства.

## `FloatingImage`

`<FloatingImage>` отображает обрезанную область растрового изображения, которая может обтекаться текстом или находиться
внутри строки. Тег также принимает явные идентификаторы текстур `modid:path`, поэтому может напрямую ссылаться на
текстурные ресурсы других модов.

### Атрибуты

| Атрибут | Обязательно. | Значение |
| --- | --- | --- |
| `src` | да | путь к изображению |
| `x` | да | начало обрезки X в пикселях исходного изображения. |
| `y` | да | начало обрезки Y в пикселях исходного изображения. |
| `width` / `w` | да | ширина обрезки в пикселях исходного изображения; необходимо использовать ровно одно написание |
| `height` / `h` | да | высота обрезки в пикселях исходного изображения; необходимо использовать ровно одно написание |
| `scaleX` | нет | множитель горизонтального отображения, по умолчанию `1.0` |
| `scaleY` | нет | множитель вертикального отображения, по умолчанию `1.0` |
| `displayWidth` | нет | окончательная ширина дисплея в пикселях; сохраняет соотношение сторон обрезки при использовании отдельно |
| `displayHeight` | нет | окончательная высота дисплея в пикселях; сохраняет соотношение сторон обрезки при использовании отдельно |
| `wrap` | нет | `inline` для истинного встроенного размещения, в противном случае используйте обычные режимы переноса. |
| `align` | нет | `left` или `right` для плавающего размещения; игнорируется, когда `wrap="inline"` |
| `title` | нет | текст всплывающей подсказки/заголовка. |
| `sound` | нет | звуковое событие, воспроизводимое всем изображением. |
| `soundSrc` | нет | путь к звуковому файлу для всего изображения. |
| `trigger` | нет | `click` по умолчанию или `hover` для воспроизведения при наведении. |

### Примечания

- `x`, `y`, `width` / `w` и `height` / `h` необходимы вместе при обрезке.
- если все атрибуты обрезки опущены, `displayWidth` или `displayHeight` отображает полное исходное изображение.
- `width` и `height` теперь описывают прямоугольник обрезки, а не конечный размер дисплея.
- `scaleX` и `scaleY` вычисляют окончательный размер дисплея как `cropWidth * scaleX` по `cropHeight * scaleY`.
- `displayWidth` или `displayHeight` задает окончательный размер дисплея в пикселях; когда присутствует только один, другой размер рассчитывается на основе соотношения сторон обрезки
- использование `displayWidth` и `displayHeight` позволяет намеренно непропорциональное растяжение.
- `displayWidth`/`displayHeight` нельзя комбинировать с `scaleX`/`scaleY`
- растяжение по одной оси поддерживается путем установки другого масштаба только на один масштаб.
- `width` с `w` или `height` с `h` недействителен и отображает видимую ошибку.
- старый контент `FloatingImage width/height as display size` намеренно считается устаревшим и требует ручного переноса.
- `src` может быть относительным, корневым или явным идентификатором текстуры `modid:path`, например `minecraft:textures/gui/options_background.png`.

### Пример

````md
<FloatingImage
  src="minecraft:textures/gui/options_background.png"
  x="0"
  y="0"
  width="32"
  height="32"
  displayWidth="64"
  displayHeight="64"
  wrap="inline"
  title="Example"
/>
````

## `ImageAnnotation`

`<ImageAnnotation>` — дочерний элемент `<FloatingImage>`, который добавляет всплывающую подсказку с форматированным текстом (и
необязательная цветная рамка) для прямоугольной области изображения. Координаты указаны в
**пиксели обрезанного изображения** автоматически пропорционально масштабируются при изменении размера обрезанного изображения.
или растянуто.

### Атрибуты

| Атрибут | Обязательно. | По умолчанию | Значение |
| --- | --- | --- | --- |
| `x` | нет | — | левый край области в пикселях изображения. |
| `y` | нет | — | верхний край области в пикселях изображения. |
| `w` | нет | — | ширина области в пикселях изображения. |
| `h` | нет | — | высота области в пикселях изображения. |
| `border` | нет | `false` | показать цветную рамку вокруг области. |
| `borderColor` | нет | случайный | цвет границы (`#RRGGBB` или `#AARRGGBB`). |
| `borderThickness` | нет | `1` | толщина границы в пикселях дисплея. |
| `sound` | нет | нет | для этого региона воспроизводится дополнительное звуковое событие. |
| `src` | нет | нет | необязательный путь к звуковому файлу; преобразован в идентификатор звукового события |
| `trigger` | нет | `click` | `click` или `hover` |

### Примечания

- если исключить все четыре параметра `x`, `y`, `w`, `h`, аннотация будет охватывать **все изображение**
- если присутствует какой-либо из четырех, остальные пропущенные по умолчанию имеют значение `0` (происхождение) или `1` (размер).
- граница **не отображается по умолчанию**; добавьте `border` или `border={true}`, чтобы включить его
- если `borderColor` опущен и включен `border`, используется случайный полностью непрозрачный цвет.
- дочернее содержимое MDX отображается как тело всплывающей подсказки и может включать в себя любые встроенные/блочные элементы.
- более поздние аннотации (ниже в списке) имеют приоритет при наведении курсора на более ранние, когда регионы перекрываются.

### Пример

Аннотация к изображению:

````md
<FloatingImage src="test1.png" align="left" x="0" y="0" width="128" height="128">
  <ImageAnnotation>
    Наведите курсор на изображение, чтобы увидеть эту подсказку.
  </ImageAnnotation>
</FloatingImage>
````

аннотация региона с видимой рамкой:

````md
<FloatingImage src="test1.png" align="left" x="0" y="0" width="128" height="128">
  <ImageAnnotation x="10" y="10" w="60" h="40" border borderColor="#FFFF4444" borderThickness="2">
    Это подсказка **выделенной области**.
  </ImageAnnotation>
</FloatingImage>
````

Несколько регионов на одном изображении:

````md
<FloatingImage src="test1.png" align="left" x="0" y="0" width="128" height="128">
  <ImageAnnotation x="0" y="0" w="64" h="64" border borderColor="#FF44FF44">
    Левая половина
  </ImageAnnotation>
  <ImageAnnotation x="64" y="0" w="64" h="64" border borderColor="#FF4444FF">
    Правая половина
  </ImageAnnotation>
</FloatingImage>
````

Области изображения также могут воспроизводить звуки. Используйте `<SoundArea>`, если вам нужен только звук, или поставьте `sound`.
непосредственно на `<ImageAnnotation>`, если тот же регион также имеет всплывающую подсказку или границу.

````md
<FloatingImage
  src="test1.png"
  align="left"
  x="0"
  y="0"
  width="128"
  height="128"
  sound="guidenh:image.click"
>
  <SoundArea x="0" y="0" w="64" h="64" sound="guidenh:image.left" />
  <SoundArea x="64" y="0" w="64" h="64" sound="guidenh:image.right" trigger="hover" />
  <ImageAnnotation x="10" y="10" w="40" h="40" border sound="guidenh:image.note">
    Эта область содержит и подсказку, и звук при нажатии.
  </ImageAnnotation>
</FloatingImage>
````

`<FloatingImage sound="...">` охватывает все изображение. Звуки региона используют координаты обрезанного изображения.
и подчиняйтесь тому же приоритету перекрытия, что и всплывающие подсказки: более поздние регионы выигрывают.

## Встраивание контента и перенос текста

Все теги уровня блока — `<FloatingImage>`, `<Recipe>`, `<GameScene>`, `<ItemImage>`, `<BlockImage>` и любые другие
теги, поддерживаемые `BlockTagCompiler`, принимают два дополнительных атрибута макета, которые
обеспечивает встраивание контента в стиле Word.

| Атрибут | Значения | По умолчанию | Значение |
| --- | --- | --- | --- |
| `wrap` | `inline` · `square` · `tight` · `through` · `top-bottom` · `behind` · `front` | `inline` | режим переноса текста |
| `align` | `left` · `center` · `right` | `left` | Горизонтальное выравнивание |

### Режимы переноса

| Режим | эквивалент слова | Поведение контекста блока | Поведение в контексте потока |
| --- | --- | --- | --- |
| `inline` | В соответствии с текстом. | Стек по умолчанию (嵌入型) | располагается в текстовой строке. |
| `square` | Квадрат | float на уровне документа; текст обтекает (方形环绕) | `FLOAT_LEFT` / `FLOAT_RIGHT` |
| `tight` | Плотно | То же, что и `square` (紧密型). | то же, что и `square`. |
| `through` | Через | То же, что и `square` (穿越型). | То же, что и `square`. |
| `top-bottom` | Верх и низ | слот полной ширины; `align` перемещает по горизонтали (上下型) | строка-вставка с разрывами |
| `behind` | За текстом | Выровненный встроенный слот; рендеринг позади текста (衬于文字下方) | Сидит на линии |
| `front` | Перед текстом | Выровненный встроенный слот; рендерится перед текстом (浮于文字上方) | Сидит на линии |

### Выравнивание с плавающей оберткой

Для `wrap=square/tight/through`:
- `align=left` (по умолчанию) — блок перемещается **влево**; текст заполняет правую часть.
- `align=right` — блок перемещается **вправо**; текст заполняет левую часть.
- `align=center` — блок центрируется без плавания (без переноса текста).

### Примеры

плавающее слева изображение с использованием нового атрибута `wrap`:

````md
<FloatingImage
  src="test1.png"
  wrap="square"
  align="left"
  x="0"
  y="0"
  width="128"
  height="128"
  scaleX="0.5"
  scaleY="0.5"
/>

Текст абзаца обтекает изображение справа.
````

Плавающий вправо рецепт:

````md
<Recipe id="minecraft:stone" wrap="square" align="right" />

Текст обтекает блок рецепта слева.
````

центрированное изображение элемента (без переноса текста):

````md
<ItemImage id="minecraft:diamond" align="center" />
````

Изображение элемента с выравниванием по правому краю:

````md
<ItemImage id="minecraft:diamond" align="right" />
````

Товар NBT может быть предоставлен отдельно от идентификатора товара. Встроенный SNBT в `id` по-прежнему поддерживается;
если присутствуют обе формы, автономный атрибут `nbt` объединяется последним.

````md
<ItemImage id="minecraft:diamond" nbt='{display:{Name:"Custom Diamond"}}' />
<ItemImage
  id="minecraft:chest"
  scale="2"
  nbt='{id:"Chest",Items:[{Slot:0b,id:"minecraft:diamond",Count:1b,Damage:0s}]}'
/>
````

> **Примечание**. `wrap="inline"` теперь обеспечивает истинное встроенное размещение `<FloatingImage>` внутри текстового текста.
> Во встроенном режиме `align` игнорируется и не вызывает ошибку.

## Иконки текстур навигации

Frontmatter может использовать `icon_texture` для отображения текстуры вместо элемента в навигации/поиске:

```yaml
navigation:
  title: Root
  icon_texture: test1.png
```

файл должен декодироваться как изображение. Путь разрешается так же, как и любой другой путь к направляющему ресурсу.

## Ресурсы, не являющиеся изображениями

Страницы GuideNH также могут ссылаться на ресурсы времени выполнения, не являющиеся изображениями, особенно на структурные файлы, например:

````md
<ImportStructure src="/assets/example_structure.snbt" />
````

эти ресурсы загружаются через один и тот же конвейер ресурсов направляющих, но используются пользовательскими тегами, а не отображаются непосредственно в виде изображений.

## Лучшие практики

- размещайте локальные изображения рядом со страницей, на которой они используются.
- храните файлы многократного использования в корневой папке руководства `assets/`.
- предпочитать корневые пути `/assets/...` для общих файлов, на которые ссылаются несколько страниц.
- используйте значки текстур только для реальных изображений.

## `BlockImage`

`<BlockImage>` использует те же правила внедрения на уровне блоков, что и `<FloatingImage>`, но визуальный
контент представляет собой прозрачный трехмерный одноблочный предварительный просмотр вместо растрового изображения. Он лучше всего подходит для
показывает, как размещенный блок выглядит в мире, но при этом соответствует обычному тексту руководства.

Ключевое поведение:

- прозрачный фон и граница.
- нет кнопок сцены, нет ползунка слоя, нет области создания аннотаций.
- при наведении курсора мыши по-прежнему отображается контур выбранного блока и всплывающая подсказка.
- `scale` изменяет масштаб камеры и по умолчанию используется `4`.
- `perspective` принимает `isometric-north-east`, `isometric-north-west` и `up`.
- `nbt` предоставляет SNBT объекта тайла; встроенный `id="mod:block:meta:{...}"` SNBT по-прежнему работает, но
автономный атрибут `nbt` легче читается и является предпочтительным.

Пример:

````md
<BlockImage id="minecraft:stone" />
<BlockImage id="minecraft:furnace" perspective="isometric-north-west" scale="2.5" />
<BlockImage
  id="minecraft:chest"
  scale="2"
  nbt='{id:"Chest",Items:[{Slot:0b,id:"minecraft:apple",Count:8b,Damage:0s}]}'
/>
````
