# 欢迎使用 GuideNH

欢迎你，<PlayerName />。

你正在阅读的是 <ItemImage id="guidenh:guide" /> **GuideNH**，一个用于在游戏内展示复杂指南内容的文档框架。

GuideNH 不只是一本普通的书。它可以把 Markdown 文本、物品链接、配方、图片、按键提示、悬浮说明，以及可交互的场景预览整合到同一个界面中。

## 如何浏览

左侧是**导航栏**，你可以通过它浏览当前指南中的页面与章节。

右上角的按钮可以用于搜索、返回首页、前进、后退，以及关闭指南界面。

当某个页面与物品建立索引后，你可以在物品栏中悬停对应物品，并按下 <KeyBind id="key.guidenh.open_guide" />，直接跳转到相关页面。

<Tooltip text="部分页面可能包含物品链接、配方、结构预览、图表或交互式说明。">
  将鼠标悬停在这里查看提示。
</Tooltip>

## 交互式内容

一些页面可能包含可交互的场景预览。它们可以用来展示机器、结构、布局或特殊机制，让你不必离开游戏也能理解复杂内容。

你可能可以：

- 旋转或缩放场景
- 查看单个方块
- 切换层级或不同变体
- 对比不同结构状态
- 阅读直接标注在场景中的说明

## 给读者的建议

第一次使用时，建议先从左侧导航栏开始，了解当前指南中有哪些内容。

遇到不熟悉的物品、机器或机制时，可以尝试搜索它的名称。

<Color color="#ffcc66">提示：</Color> GuideNH 更适合把内容拆分成多个相互关联的小页面，而不是写成一篇过长的说明文档。

## 给作者的说明

GuideNH 页面使用带有 frontmatter 元数据的 Markdown 编写。

作者可以使用 GuideNH 专用标签，例如 <ItemImage id="minecraft:paper" />、<KeyBind id="key.attack" />、悬浮提示、物品引用、配方预览和场景组件，让游戏内文档更容易阅读和维护。

它的目标不只是展示文字，而是让复杂信息变得更清晰、更直观、更容易探索。

## 开始使用吧

GuideNH 会帮助你更快找到答案，也能帮助作者更好地组织内容。

把它当作地图、参考书，以及理解复杂系统的工具来使用吧。
